BioTime Connect Pro

The complete ZKTeco BioTime 8.x / 9.x / Cloud integration for Odoo 19 Attendance. One module instead of six: two-way sync, smart punch pairing, late and overtime rules, a built-in job queue, device monitoring and a dashboard.

Connectivity

  • BioTime 8.x, 9.x and BioTime Cloud
  • Token, JWT and HTTP Basic authentication
  • Multiple servers, multi-company with record rules
  • Device timezone conversion

Two-way sync

  • Pull punches, devices and employees
  • Push departments, work locations (areas) and employees
  • Push all employees or only those assigned to a server
  • 1 request for all transactions, or 1 per device
  • Custom date-range wizard with device / employee filters
  • Idempotent: re-pulling never creates duplicates

Attendance engine

  • Explicit IN/OUT or alternating punch pairing
  • Double-punch filter, night shifts across midnight
  • Late In / early out minutes from the employee working schedule (auto re-evaluated)
  • Break deduction, net hours and overtime
  • Missing check-out detection and auto-close

Reliability & control

  • Built-in job queue, no extra module needed; retries after 1, 5, 10, 30 min
  • Raw punch audit trail with Pending / Processed / Error / Skipped, one-click retry or skip
  • Sync logs, device online/offline, firmware and user counts
  • Dashboard (graph and pivot) and three access levels: User, Supervisor, Manager
